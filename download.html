Installing

A few notes for first launch

Windows

If SmartScreen shows "Windows protected your PC", click More info, then Run anyway. This appears for new apps until they build a reputation.

macOS

Open the .dmg and drag Kelvora to Applications. The first time, right-click the app and choose Open.

Linux

Install the .deb with your package manager, or make the AppImage executable and run it.

sudo apt install ./kelvora_amd64.deb
